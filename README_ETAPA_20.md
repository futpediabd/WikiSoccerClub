# WikiSoccerClub — Etapa 20

Esta etapa conecta os resultados das partidas à competição.

## Adicionado

- Modelo completo da tabela de classificação.
- Pontos, jogos, vitórias, empates e derrotas.
- Gols pró, gols contra e saldo de gols.
- Critérios de desempate:
  1. Pontos
  2. Vitórias
  3. Saldo de gols
  4. Gols pró
- Atualização automática após cada resultado.
- Controle de rodadas.
- Marcação de partidas disputadas.
- Avanço automático para a próxima rodada.
- Busca do próximo jogo do time.
- Repositório local do progresso da competição.
- Tela de classificação.
- Tela com jogos e resultados por rodada.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.
