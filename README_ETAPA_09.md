# WikiSoccerClub — Etapa 09

Atualização da competição com jogadores, autores dos gols e artilharia.

## Adicionado

- Elencos de teste para todos os clubes da competição.
- Finalização individual dos jogadores.
- Sorteio ponderado do autor de cada gol.
- Minuto de cada gol.
- Registro dos eventos de gols dentro das partidas.
- Motor de artilharia.
- Ranking de artilheiros.
- Tela de artilharia.
- Botão Artilharia na central da competição.
- Rota TOP_SCORERS integrada ao aplicativo.
- Estrutura inicial de detalhes da partida.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.
