# WikiSoccerClub — Etapa 23

Esta etapa adiciona a fase de grupos às competições.

## Adicionado

- Configuração de quantidade de grupos e times.
- Distribuição em serpentina para equilibrar os grupos.
- Validação contra times duplicados.
- Geração automática dos jogos.
- Turno único ou jogos de ida e volta.
- Tabela independente para cada grupo.
- Atualização automática após cada resultado.
- Avanço automático de rodadas.
- Classificação dos melhores de cada grupo.
- Conversão de uma fase com 8 grupos para as oitavas de final.
- Repositório e ViewModel da fase de grupos.
- Tela das classificações por grupo.
- Tela dos jogos por rodada e grupo.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.
