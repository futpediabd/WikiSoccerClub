# WikiSoccerClub — Etapa 34

Esta etapa adiciona o sistema financeiro do clube.

## Adicionado

- Saldo do clube.
- Orçamento para transferências.
- Orçamento salarial.
- Folha salarial mensal dos jogadores.
- Salários mensais da comissão técnica.
- Custos mensais da base.
- Custos mensais do estádio.
- Processamento financeiro ao avançar o mês.
- Receitas e despesas registradas individualmente.
- Resumo financeiro mensal.
- Validação de saldo para transferências.
- Cálculo do orçamento salarial disponível.
- Propostas de patrocínio.
- Bônus de assinatura.
- Pagamento mensal de patrocinadores.
- Bônus por conquista de títulos.
- Contratos de patrocínio com duração definida.
- Premiações por competição.
- Premiação para campeão, vice, semifinalista e participante.
- Repositório financeiro.
- ViewModel integrado.
- Tela de finanças.
- Tela de propostas de patrocinadores.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem a estrutura das etapas anteriores. O código não foi compilado
contra o projeto Android real nesta sessão; rotas, componentes visuais, temas
ou modelos já existentes podem precisar de pequenos ajustes de integração.
