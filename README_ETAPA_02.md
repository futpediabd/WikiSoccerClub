# WikiSoccerClub — Etapa 02

Projeto acumulativo completo, já contendo a Etapa 01.

## Adicionado nesta etapa

- Navegação funcional entre todas as opções do menu.
- Tela Novo Jogo.
- Seleção de clube carregado dos arquivos BAN.
- Campo para nome do treinador.
- Criação e salvamento local da carreira com DataStore.
- Tela Carregar Jogo.
- Tela inicial da carreira.
- Editor inicial exibindo clubes e jogadores importados.
- Tela de créditos.
- Estrutura preparada para calendário, competições e partidas.

## Instalação

Substitua o projeto anterior pelo conteúdo desta pasta ou abra diretamente no Android Studio.
