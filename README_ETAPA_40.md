# WikiSoccerClub — Etapa 40

Esta etapa adiciona o sistema completo de rivalidades entre clubes.

## Adicionado

- Rivalidades locais, estaduais, regionais, nacionais, continentais e internacionais.
- Descoberta automática da abrangência geográfica.
- Criação automática de rivalidades por frequência de confrontos.
- Rivalidades fortalecidas por finais e decisões de títulos.
- Pontuação de intensidade entre 0 e 100.
- Níveis baixo, moderado, alto, feroz e histórico.
- Histórico completo de confrontos.
- Vitórias, empates, derrotas e gols.
- Registro de finais disputadas.
- Registro de decisões de título.
- Maior vitória de cada clube.
- Maior público do confronto.
- Lista dos dez confrontos mais recentes.
- Bônus de intensidade para o motor de partidas.
- Multiplicador de público em clássicos.
- Redução gradual de rivalidades pouco disputadas.
- Proteção para rivalidades históricas.
- Repositório de rivalidades e partidas.
- ViewModel integrado.
- Tela de rivalidades.
- Tela de detalhes e retrospecto.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem a estrutura das etapas anteriores. O código não foi compilado
contra o projeto Android real nesta sessão; rotas, componentes visuais, temas
ou modelos existentes podem precisar de pequenos ajustes de integração.
