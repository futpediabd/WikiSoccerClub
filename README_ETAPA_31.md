# WikiSoccerClub — Etapa 31

Esta etapa adiciona inteligência artificial ao mercado de transferências.

## Adicionado

- Perfis financeiros e esportivos dos clubes.
- Identificação de carências por posição.
- Prioridades baixa, média, alta e urgente.
- Avaliação automática de jogadores disponíveis.
- Pontuação baseada em overall, potencial, idade e disponibilidade.
- Limite de ofertas conforme o saldo do clube.
- Valor automático das propostas.
- Salário sugerido pela inteligência artificial.
- Aceite, recusa ou contraproposta automática do clube vendedor.
- Valorização de jovens com alto potencial.
- Desconto para jogadores listados para venda.
- Repositório da simulação do mercado.
- ViewModel da inteligência artificial.
- Tela de movimentações dos clubes.
- Tela de necessidades dos elencos.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem a estrutura das etapas anteriores. O projeto real ainda não
foi compilado nesta sessão; rotas, componentes visuais, temas ou modelos podem
precisar de pequenos ajustes na integração final.
