# WikiSoccerClub — Etapa 26

Esta etapa implementa a transição real entre temporadas.

## Adicionado

- Promoção e rebaixamento entre divisões.
- Validação para impedir times em duas divisões.
- Registro de todas as movimentações.
- Arquivamento dos campeões da temporada.
- Preparação automática da temporada seguinte.
- Envelhecimento anual dos jogadores.
- Evolução de jovens conforme potencial.
- Queda de overall após os 34 anos.
- Expiração de contratos.
- Aposentadoria por idade e nível.
- Repositório de temporada ampliado.
- ViewModel da transição.
- Tela de promoções e rebaixamentos.
- Tela de atualização dos jogadores.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem os pacotes usados nas etapas anteriores. Como o projeto real
ainda não foi compilado nesta sessão, nomes de componentes, temas ou modelos
podem exigir pequenos ajustes de integração.
