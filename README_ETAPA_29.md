# WikiSoccerClub — Etapa 29

Esta etapa amplia o mercado com empréstimos e contratos.

## Adicionado

- Propostas de empréstimo.
- Taxa mensal de empréstimo.
- Divisão do pagamento de salário.
- Opção de compra.
- Aceitar e recusar empréstimos.
- Encerramento automático de empréstimos.
- Compra definitiva durante o empréstimo.
- Propostas de contrato.
- Salário mensal.
- Bônus de assinatura.
- Multa rescisória.
- Aceitar, recusar e realizar contraproposta.
- Controle de contratos ativos.
- Identificação de contratos próximos do fim.
- Repositórios de empréstimos e contratos.
- ViewModel integrado.
- Tela de empréstimos.
- Tela de negociações contratuais.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos continuam a estrutura das etapas anteriores. Como o código não foi
compilado contra o projeto Android real nesta sessão, rotas, componentes visuais
ou nomes de modelos podem exigir pequenos ajustes de integração.
