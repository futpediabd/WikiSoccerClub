# WikiSoccerClub — Parte 7, Etapa 7.3

Esta etapa adiciona o sistema de sorteios e resolução do mata-mata:

- sorteio ao vivo da fase de grupos;
- grupos com quatro clubes;
- limite de dois clubes do mesmo país por grupo;
- sorteio ao vivo antes de cada fase eliminatória;
- confrontos de ida e volta;
- definição de mando para o clube de menor nível;
- mando aleatório quando os níveis são iguais;
- mata-mata em jogo único para o Super Mundial;
- resolução pelo placar agregado;
- ausência da regra de gol fora;
- decisão por pênaltis em caso de empate;
- registro dos eventos do sorteio para exibição futura na interface.
