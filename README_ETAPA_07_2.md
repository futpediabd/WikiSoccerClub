# WikiSoccerClub — Parte 7, Etapa 7.2

Incluído nesta etapa:

- grupos de 4 para competições com até 32 clubes;
- mata-mata desde o início para competições com 64 clubes;
- geração automática das fases;
- calendário básico de grupos e mata-mata;
- marcações de vagas, acesso, playoffs e rebaixamento;
- repositório de configuração por temporada;
- serviço inicial para criação das competições da temporada.
