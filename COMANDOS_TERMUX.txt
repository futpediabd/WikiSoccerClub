1. Abra o Termux.

2. Entre na pasta de downloads:
cd /storage/emulated/0/Download

3. Apague somente a pasta temporária antiga:
rm -rf WikiSoccerClub_FullGame

4. Extraia o ZIP:
unzip -o WikiSoccerClub_Integracao_Parte07_Etapa07_4.zip

5. Copie os arquivos para o projeto:
cp -r WikiSoccerClub_FullGame/. ~/WikiSoccerClub/

6. Entre no projeto:
cd ~/WikiSoccerClub

7. Confira os arquivos alterados:
git status

8. Adicione as alterações:
git add .

9. Crie o commit:
git commit -m "Parte 7.4 - Avanco classificacao e encerramento das competicoes"

10. Envie ao GitHub:
git push
