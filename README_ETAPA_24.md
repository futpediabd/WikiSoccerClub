# WikiSoccerClub — Etapa 24

Esta etapa conecta a fase de grupos ao mata-mata.

## Adicionado

- Modelo de competição híbrida.
- Controle das fases:
  - Fase de grupos.
  - Mata-mata.
  - Competição concluída.
- Criação automática da fase de grupos.
- Transição automática para as oitavas de final.
- Cruzamento entre líderes e segundos colocados.
- Continuidade automática até a final.
- Identificação do campeão.
- Repositório próprio da competição híbrida.
- ViewModel central.
- Tela principal da competição.
- Tela de times classificados.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos foram preparados para continuar a estrutura das etapas anteriores.
A integração final pode exigir ajuste dos nomes de rotas, componentes e modelos
já existentes no projeto real.
