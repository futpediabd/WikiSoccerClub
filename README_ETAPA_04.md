# WikiSoccerClub — Etapa 04

Projeto acumulativo completo com as etapas anteriores.

## Adicionado nesta etapa

- Calendário inicial com cinco eventos jogáveis.
- Avanço real por evento, sem avanço diário.
- Tela de elenco com limite visual de 35 jogadores.
- Geração automática de elenco quando o BAN possui poucos jogadores.
- Escalação automática com 11 titulares e 7 reservas.
- Tela de escalação antes da partida.
- Simulador inicial com gols, finalizações, posse e eventos.
- Tela de resultado.
- Salvamento automático do evento concluído.
- Retorno à tela principal com o próximo jogo atualizado.
