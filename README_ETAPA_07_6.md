# WikiSoccerClub — Parte 7, Etapa 7.6

Esta etapa adiciona a transição entre temporadas:

- promoções e rebaixamentos;
- movimentação automática entre divisões;
- geração das vagas da temporada seguinte;
- substituição de clubes inelegíveis;
- armazenamento do resultado da transição;
- integração inicial com o calendário global;
- detecção de conflitos entre competições;
- remanejamento automático de datas conflitantes;
- preparação para o botão "Avançar temporada".

Os repositórios em memória continuam como base provisória até a ligação
definitiva com o banco de dados e o sistema geral de salvamento.
