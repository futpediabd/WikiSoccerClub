# WikiSoccerClub — Etapa 30

Esta etapa conclui o fluxo básico das transferências.

## Adicionado

- Finalização de transferências permanentes.
- Validação de saldo do clube comprador.
- Crédito automático para o clube vendedor.
- Remoção do jogador do elenco antigo.
- Inclusão do jogador no novo elenco.
- Validação para impedir jogadores duplicados.
- Compra definitiva após empréstimo.
- Contratação de jogadores sem clube.
- Salário mínimo para agentes livres.
- Bônus de assinatura.
- Contrato automático para o novo clube.
- Histórico de transferências.
- Consulta por jogador, clube ou temporada.
- Repositório financeiro e de elencos.
- ViewModel central de conclusão.
- Tela de transferência concluída.
- Tela de histórico do mercado.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem a estrutura das etapas anteriores. Eles não foram compilados
contra o projeto Android real nesta sessão; nomes de componentes, rotas, temas
ou modelos podem exigir ajustes durante a integração final.
