# WikiSoccerClub — Etapa 22

Esta etapa adiciona competições eliminatórias.

## Adicionado

- Modelo de mata-mata.
- Confrontos de ida e volta.
- Final em jogo único.
- Resultado agregado.
- Decisão por pênaltis em caso de empate.
- Definição automática do classificado.
- Criação automática da fase seguinte.
- Suporte a fases preliminares, 128 avos, 64 avos, 32 avos,
  oitavas, quartas, semifinais e final.
- Identificação automática do campeão.
- Repositório local das competições eliminatórias.
- ViewModel de controle do mata-mata.
- Tela de chaveamento.
- Tela do campeão.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.
