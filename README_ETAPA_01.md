# WikiSoccerClub — Etapa 01

Esta etapa contém a fundação do projeto Android nativo em Kotlin + Jetpack Compose.

## Incluído

- Tema oficial verde, amarelo, branco e azul-escuro.
- Logo oficial na tela inicial.
- Menu inicial com:
  - Novo Jogo
  - Carregar Jogo
  - Editor
  - Créditos
- Estrutura de assets:
  - `teams/`
  - `teams/escudos/`
  - `bandeiras/`
- Parser inicial de arquivos `.ban`.
- Conversão de nível BAN para força e estrelas.
- Exemplo de clube BAN.

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta `WikiSoccerClub_Etapa_01` no Android Studio.
3. Aguarde a sincronização do Gradle.
4. Execute em um dispositivo ou emulador Android 7.0 ou superior.

## Observação

O menu ainda é visual nesta etapa. As telas internas e os sistemas de carreira serão conectados nas próximas entregas.
