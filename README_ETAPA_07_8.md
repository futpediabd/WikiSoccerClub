# WikiSoccerClub — Parte 7, Etapa 7.8

Esta etapa foi criada sobre o projeto completo atualizado enviado pelo usuário.

Incluído:

- coordenador central para integrar todas as competições da temporada;
- validação global antes da criação das competições;
- criação conjunta de estaduais, copas, continentais e mundial;
- integração dos calendários;
- detecção de conflitos entre competições;
- remanejamento automático de datas conflitantes;
- relatório global de competições criadas;
- lista consolidada de avisos;
- coordenador do avanço de temporada;
- ligação com promoções, rebaixamentos e classificações do ano seguinte.

Os arquivos foram preparados para usar diretamente as classes já existentes
das Etapas 7.1 até 7.7 no projeto atual.
