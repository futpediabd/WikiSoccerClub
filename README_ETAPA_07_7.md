# WikiSoccerClub — Parte 7, Etapa 7.7

Esta etapa fecha a primeira integração estrutural do sistema de competições.

Incluído:

- criação automática das competições oficiais;
- seleção de participantes conforme o tipo da competição;
- criação de estaduais;
- criação de copas regionais;
- criação de copas nacionais;
- criação das competições continentais;
- criação do Super Mundial;
- regras de prioridade para classificação;
- substituição de clubes impedidos nas copas regionais;
- tamanhos automáticos para copas nacionais e Super Mundial;
- fábrica de competições;
- integração com calendário;
- gravação da configuração da temporada;
- validação de clubes duplicados e vagas insuficientes.

Esta etapa usa as classes das Etapas 7.1 até 7.6.
