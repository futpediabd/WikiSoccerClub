# WikiSoccerClub — Etapa 32

Esta etapa adiciona o sistema de observação e descoberta de jogadores.

## Adicionado

- Cadastro de olheiros.
- Qualidade de avaliação de overall.
- Qualidade de avaliação de potencial.
- Adaptabilidade por nacionalidade.
- Missões de observação por país.
- Filtro por posição, idade e overall.
- Duração das missões em dias.
- Progresso das observações conforme o calendário.
- Relatórios automáticos ao concluir uma missão.
- Níveis de conhecimento do jogador.
- Faixas estimadas de overall e potencial.
- Faixa estimada de valor de mercado.
- Nota de recomendação.
- Observação textual automática.
- Lista de observação de jogadores.
- Prioridades de acompanhamento e negociação.
- Repositórios de olheiros, relatórios e lista.
- ViewModel integrado.
- Tela de missões de observação.
- Tela de relatórios.
- Tela da lista de jogadores acompanhados.

## Instalação

Extraia o ZIP na raiz do projeto e confirme a substituição dos arquivos existentes.

## Observação

Os arquivos seguem a estrutura das etapas anteriores. O código não foi compilado
contra o projeto Android real nesta sessão; rotas, componentes visuais, temas
ou nomes de modelos podem precisar de pequenos ajustes de integração.
